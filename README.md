# Unit Converter Website

This is a simple website that allows users to convert units between imperial and metric systems. It supports conversions for length, volume, and mass.

## Features

- **Length Conversion**: Meters to Feet and Feet to Meters
- **Volume Conversion**: Liters to Gallons and Gallons to Liters
- **Mass Conversion**: Kilograms to Pounds and Pounds to Kilograms

## Technologies Used

- **HTML**
- **CSS**
- **JavaScript**

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/hani-2020/unit-converter-website.git
   ```
2. Navigate to the project directory:
   ```
   cd unit-converter-website
   ```
3. Open `index.html` in a web browser to view the website.

## Usage

1. Enter a value in the input field.
2. The website will automatically calculate and display the equivalent values in the imperial and metric systems for length, volume, and mass.
